# NativeLocation 隐私政策（草稿）

最后更新：2026-08-14

本应用（NativeLocation）由运营方在自有服务器上提供位置上报服务。上架前请将本文托管为 **HTTPS 可访问页面**，并把 URL 填入 App Store / Google Play。

## 我们收集的信息

- 设备生成的 `deviceId`（用于区分设备，不强制绑定个人身份）。
- 在你开启定位期间采集的 **WGS84 经纬度** 及精度、海拔、速度、航向、采集时间。
- 你选择的采集频率仅保存在本机。

## 用途

用于将位置点上报到你配置的服务端并存储，以便轨迹与业务使用。

## 权限

- 定位（使用期间）：开启定位时需要。
- 本期生产版本不在后台持续定位。你可以在系统设置中关闭定位授权。

## 存储与保留

数据保存在运营方的 PostgreSQL 中。保留期限由运营方自行规定并在实际上架文案中写明。

## 第三方

位置来自系统定位服务（iOS Core Location / Android Location）。不向地图或广告 SDK 分享，除非运营方另行声明。
