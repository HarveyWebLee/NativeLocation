## 背景与目标

需要可安装到 iOS / Android 的定位能力：手机端在前台采集位置，服务端校验后写入 PostgreSQL，便于后续对接业务或外部云。

成功标准：

- 真机可完成：注册设备 → 授权 → 开启定位 → 服务端入库可见。
- 短时断网后可通过 HTTP 批量补传。
- 前后端共用同一套位置数据契约。

## 范围

### 本期（In Scope）

对应总 FRD `S-01`～`S-07`：设备注册与本地 `deviceId`、定位权限（申请前台+后台 / 引导系统设置取消）、仅时间间隔采集与可切换频率、WS 实时上报 + HTTP 兜底、服务端校验落库、健康检查、后台 Task **代码预留**（不默认开启追踪，无独立后台权限按钮）。

功能明细见总 FRD 第 4～6 章（含 `FR-LOC-01`～`07`、`FR-UP-*`、`FR-API-01`～`04`、`FR-CFG-01`）。

### 明确不做

对应总 FRD `O-01`～`O-07`。后台持续上报见 `FR-LOC-06`（P2）。App 不能直接收回系统定位权限。不提供每秒 5 次采集选项。

## 已决（原待确认项）

| 项           | 结论                                                                              |
| ------------ | --------------------------------------------------------------------------------- |
| 端形态       | 手机 App（Expo），不用 Electron                                                   |
| 上报主路径   | WebSocket，HTTP 批量兜底                                                          |
| 存储         | PostgreSQL + Prisma；MVP 无对外查询 HTTP API                                      |
| 后台定位     | 申请权限时一并请求后台；Task 预留，不默认追踪；无独立「申请后台权限」按钮         |
| 取消授权     | 打开系统设置由用户关闭；返回后若未授予前台权限则立即停止定位                      |
| 权限按钮范围 | 「使用期间」前台 + 后台一起申请；按钮文案按是否已有前台权限切换                   |
| 采集频率     | 每秒 2 次 / 每秒 1 次（默认）/ 每 3、5、10、15、20 秒；追踪中改频率立即重启 watch |
| 位移阈值     | 不保留；到点必采必报，`recordedAt` 用采集时刻                                     |
| 每秒 5 次    | 删除该选项                                                                        |
| 鉴权         | MVP 内网/开发环境可不做；生产后续                                                 |
| UI           | Tamagui；iOS 与 Android 均需可用；启停为同一按钮两态，不增加多余操作按钮          |
| 坐标系       | iOS / Android / Web 系统定位均为 WGS84，上报不做 GCJ-02 等偏移转换                |
